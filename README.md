# Rivo

*Your movies. Any screen.*

Домашний медиасервер для Windows 10/11: собирает фильмы и сериалы с дисков ПК в библиотеку с постерами TMDB, играет их в собственном плеере, транслирует на ТВ (Google Cast) и умеет смотреть торренты во время загрузки. Всё работает внутри локальной сети, телеметрии нет.

## Что внутри

| Часть | Где | Технологии |
|---|---|---|
| Медиасервер | `server/` | Go, SQLite (modernc, без cgo), ffmpeg/ffprobe, anacrolix/torrent, go-chromecast |
| Интерфейс | `web/` | React 18 + TypeScript + Vite, hls.js; шрифты Inter Tight / Inter / JetBrains Mono лежат локально |
| Оболочка Windows | `desktop/` | Tauri 2: окно, трей, автозапуск, magnet-ссылки, установщик NSIS |

Интерфейс собирается в `server/internal/webui/dist` и встраивается в бинарник сервера, поэтому тот же UI открывается с телефона или браузера ТВ по адресу `http://<IP ПК>:8096`.

### Возможности

- **Библиотека.** Папки отслеживаются (fsnotify + пересканирование раз в 30 минут), разбор имён вида `Title.2014.1080p`, `S01E02`, `1x02`, «Сезон 1 / Серия 2». Метаданные, постеры и актёры из TMDB (ключ v3 или токен v4), ручное исправление совпадения. Отключённый диск не стирает записи.
- **Плеер.** Прямое воспроизведение с Range, либо HLS-транскод через ffmpeg с аппаратным ускорением (NVENC / Quick Sync / AMF / VAAPI, иначе CPU), тонмаппинг HDR → SDR, выбор аудиодорожки, субтитры SRT/ASS/VTT (внешние и встроенные, CP1251 распознаётся) со сдвигом, PGS/VobSub вжигаются. Горячие клавиши, скорость, автопереход к следующей серии, внешний плеер VLC/mpv.
- **Позиция просмотра** синхронизируется между ПК и ТВ; «Продолжить просмотр», избранное, «Посмотреть позже», отметки «просмотрено».
- **ТВ.** Поиск Google Cast устройств по mDNS, добавление по IP, пульт: пауза, перемотка, громкость, смена дорожек, «Продолжить на ПК». Плееры подключены через интерфейс `Renderer`, DLNA/AirPlay добавляются отдельными реализациями.
- **Торренты.** Magnet / `.torrent` (в том числе перетаскиванием), «Смотреть сразу» с последовательной загрузкой и буфером, карта кусков, очередь, приоритеты, лимиты скорости, расписание, раздача до рейтинга/времени, контроль свободного места. Привязка к интерфейсу VPN с kill switch, SOCKS5-прокси, шифрование. Готовые загрузки переносятся в библиотеку как `Название (Год)/…` и `Сериал/Season N/…`. Исполняемые файлы из раздач блокируются. Поиск только по источникам Torznab (Jackett / Prowlarr), которые пользователь добавляет сам.
- **Профили** (до 5) с PIN, своей темой и историей. Темы: светлая, тёмная, OLED; четыре акцентных цвета; «живой» фон.
- **Безопасность.** Сервер отвечает только адресам локальной сети, по желанию пароль для других устройств (на самом ПК не спрашивается). ТВ получают ссылки с подписанными токенами на 6 часов.
- **Обслуживание.** Резервная копия и восстановление БД, экспорт просмотренного в CSV, диагностика (ffmpeg, сеть, ТВ, TMDB, порт торрентов, VPN, диск), журнал.
- **Языки:** русский и английский.

## Установка

Готовый установщик собирает GitHub Actions (`.github/workflows/build.yml`) на `windows-latest`: артефакт `Rivo-windows-installer` у каждого запуска, а при пуше тега `v*` — релиз с `.exe`. Установщик кладёт рядом сервер и LGPL-сборку FFmpeg (BtbN) и добавляет правило брандмауэра Windows только для частных сетей.

Данные лежат в `%APPDATA%\HomeCinema` (база, кэш картинок и транскода, логи). Папка данных и модуль Go остались от прежнего названия, чтобы обновление не потеряло библиотеку; установщик Rivo сам удаляет старую установку HomeCinema.

## Фирменный стиль

Палитра: лаванда `#A5B4FC` (бренд), лёд `#E7ECF7` (фон), ирис `#5B6EE1` (действия), мята `#8EDCC8` (акценты, прогресс), ночь `#141A33` (текст, тёмная тема). Заголовки — Inter Tight 800–900, интерфейс — Inter. Знак — кольцо с наклонённым квадратом-искрой, логотип — «rıvo». Иконки приложения собираются из `desktop/app-icon.png` (`npm run icons` в `desktop/`), исходник — `desktop/app-icon.svg`.

## Разработка

Нужны Go 1.26+, Node 20+, ffmpeg в `PATH`; для оболочки ещё Rust и WebView2.

```bash
# сервер (API на :8096)
cd server && go run ./cmd/homecinema -dev -data ./devdata

# интерфейс с hot reload (прокси /api → :8096)
cd web && npm ci && npm run dev

# сборка UI внутрь сервера и тесты
cd web && npm run build
cd server && go test ./... && go build ./cmd/homecinema
```

Оболочка Windows:

```bash
# положите бинарники с суффиксом целевой платформы:
#   desktop/src-tauri/binaries/rivo-server-x86_64-pc-windows-msvc.exe
#   desktop/src-tauri/binaries/ffmpeg-x86_64-pc-windows-msvc.exe
#   desktop/src-tauri/binaries/ffprobe-x86_64-pc-windows-msvc.exe
cd desktop && npm ci && npx tauri build
```

Флаги сервера: `-data`, `-listen` (по умолчанию `0.0.0.0:8096`, при занятом порте пробует следующие), `-ffmpeg`, `-ffprobe`, `-dev`, `-exit-on-stdin-close` (для оболочки). Когда сервер готов, он печатает `HOMECINEMA_READY http://127.0.0.1:<порт>` — по этой строке оболочка открывает окно.

## Что проверено, а что нет

Проверено в Linux-контейнере: сканирование и разбор имён (юнит-тесты), прямое воспроизведение и HLS-транскод HEVC 10-bit на CPU в браузере, внешние субтитры, добавление торрента, раздача и автоимпорт в библиотеку, все экраны интерфейса. Rust-оболочка проходит `cargo check` под `x86_64-pc-windows-msvc`.

Не проверено вживую: запросы к TMDB (нужен ключ), трансляция на реальный Chromecast, аппаратные кодировщики, привязка к VPN на Windows, собранный установщик.

## Лицензии

FFmpeg поставляется в LGPL-сборке как отдельные `ffmpeg.exe` / `ffprobe.exe`. Ответственность за законность загружаемого и раздаваемого через торренты контента лежит на пользователе; в приложении нет встроенных трекеров или источников.
